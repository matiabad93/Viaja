# Viaja

Aplicación de planificación de viajes: guías, itinerarios diarios, calendario, actividades completadas, fotografías y gastos.

## Estado de la exportación

Transferencia del código existente en curso. Este repositorio aún no constituye un despliegue independiente verificado.

## Privacidad

La demo almacena los viajes en el navegador. No incluye datos personales ni credenciales de producción. Las claves de servicios deben configurarse exclusivamente en el backend.
